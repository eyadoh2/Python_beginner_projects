# Beginner Python Projects 

A collection of beginner-friendly Python command-line projects built to practice core programming concepts such as control flow, loops, functions, and random number generation.

---##  Projects Included### 1. Binary Converter (`binary_conversion.py`)
A utility script that allows users to convert numbers between decimal and binary systems.
- 
**Features:**
- Interactive menu to choose conversion direction (Decimal to Binary or Binary to Decimal).
- Input validation and clear formatted output.

### 2. Number Guessing Game (`number_guessing_game.py`)
An interactive game where the computer picks a random number within a custom range defined by the user.
- 
**Features:**
- Custom range selection (start and end bounds).
- Input boundaries enforcement (prompts user if input is out of range).
- Real-time hints (too high / too low).
- Attempt counter to track how many tries it took to win.

### 3. Dice Rolling Simulator (`roll_dice.py`)
A simulation game that lets users roll virtual dice for a set number of rounds.
- 
**Features:**
- Custom round selection.
- Live tracking of remaining turns.
- Replay option to play again or exit upon completion.

---

## Technologies Used
- 
**Language:** Python 3.x
- 
**Concepts:** Control Flow, Loops (`while`, `for`), Functions, Conditional Statements, and the `random` module.
